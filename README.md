# TalentLens AI™ | Intelligent Candidate Evaluation Platform 🚀

![TalentLens AI Logo](https://res.cloudinary.com/dlde5yjzk/image/upload/v1777479026/Upload_Analysis_Icon_hj9qim.png)

**TalentLens AI™** is an enterprise-grade, AI-powered recruitment platform designed to automate resume screening with deep semantic reasoning. Built with an "Antigravity" 3D design philosophy, it leverages Multi-Agent AI systems to find the top 1% of talent while eliminating manual bias.

---

## 💎 The Antigravity Edge (Unique Features)

- **3D Antigravity UI:** A high-end Glassmorphism interface with floating cards, glowing effects, and responsive design.
- **Multi-Agent Evaluation:** Uses a "Recruitment Panel" of 3 AI Agents (Skeptic, Scout, and Moderator) to analyze resumes beyond simple keywords.
- **Top Talent Pulse:** Automatic visual identification of candidates with >75% match using neon-pulse animations.
- **Strict Resume Validation:** A built-in "Gatekeeper" agent that rejects non-resume documents (e.g., recipes, blank files) to ensure data integrity.
- **Agentic Insights:** Generates custom interview questions based on each candidate's specific skill gaps.

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit (Custom 3D CSS & Glassmorphism)
- **AI Brain:** Gemini 1.5 Flash (Google AI)
- **Orchestration:** Multi-Agent Prompt Engineering
- **Visuals:** Plotly (Analytics), Lottie (Animations), Cloudinary (Assets)
- **Data:** Python, Pandas, PDFPlumber, Session State Persistence

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone [https://github.com/yourusername/TalentLens-AI.git](https://github.com/yourusername/TalentLens-AI.git)
cd TalentLens-AI
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Application
```bash
streamlit run app.py
```

### 4. Configuration
- Open the sidebar in the app.
- Enter your **Gemini API Key** (Get it from [Google AI Studio](https://aistudio.google.com/)).
- Upload a Job Description and one or more Resumes to begin the scan.

## 📊 Dashboard & Analytics
TalentLens AI™ provides a holistic view of your talent pool:
- **Skill Pool Mix:** Pie chart distribution of core technologies.
- **Candidate Comparison:** Bar charts ranking the Top 5 candidates.
- **Automated Shortlist:** One-click export of top-performing talent.

---

## 🛡️ Privacy & Reliability
- **Local Processing:** Resumes are processed in memory and never stored permanently.
- **Rate-Limit Handling:** Built-in retry logic to manage Gemini API quotas gracefully.
- **Responsive:** Designed to work across Desktop, Tablet, and Mobile browsers.
